Songbook Generator

A Python program for generating summer songbooks. Users specify how many songs they want, and the program randomly selects from a spreadsheet of songs in various languages and genres.

The program fetches lyrics from the internet, letting the user choose the best source, and exports each song to a text file. This allows users to easily copy the lyrics into tools like Word or InDesign to create a professional-looking songbook.

Designed for flexibility and fun, with room for extending features such as improved filtering, custom selections, or advanced export options.
